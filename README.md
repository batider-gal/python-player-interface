# Python Player Movement System

A simple Python project that demonstrates Object-Oriented Programming (OOP) through a player movement system.

## Features

- Generate random player movements.
- Track player positions and movement history.
- Support movement in four directions.
- Unlock diagonal movements using `level_up()`.

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## Python Concepts

- Abstract Classes (`ABC`)
- Abstract Methods (`@abstractmethod`)
- Inheritance
- Method Overriding
- `super()`
- Lists and Tuples
- Random Module

## How to Run

Run the Python file:

```bash
python player_movement.py
```
